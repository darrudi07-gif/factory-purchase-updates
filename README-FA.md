# نرم‌افزار نصبی دفتر خرید کارخانه

## راه‌اندازی اولیه (ویندوز)
۱. تمام فایل‌های این بسته (از جمله پوشه مخفی `.github`) را در ریشه مخزن `darrudi07-gif/factory-purchase-updates` آپلود کنید؛ فایل‌های قبلی `index.html` و `version.json` را فعلاً می‌توانید نگه دارید.
۲. نیازی به اجرای npm روی کامپیوتر شما نیست؛ GitHub Actions هنگام ساخت، وابستگی‌ها را نصب می‌کند.
۳. در GitHub به **Settings → Actions → General → Workflow permissions** بروید و **Read and write permissions** را انتخاب کنید.
۴. در GitHub یک tag با نام `v7.0.0` ایجاد و push کنید؛ GitHub Actions فایل نصب NSIS را می‌سازد و در بخش **Releases** منتشر می‌کند.
۵. نصب‌کننده را از Releases دریافت و نصب کنید. نسخه‌های بعدی با tag جدید، `package.json` با نسخه جدید و فایل‌های برنامه جدید منتشر می‌شوند؛ بروزرسانی در برنامه دانلود و با تأیید شما نصب می‌شود.

## حفاظت از اطلاعات
- فاکتورها، پرداخت‌ها، چک‌ها و پیوست‌ها در IndexedDB داخل پروفایل ثابت Electron ذخیره می‌شوند و در بروزرسانی معمولی حفظ می‌شوند.
- **داده‌های نسخه HTML که در Chrome باز کرده‌اید خودکار به Electron منتقل نمی‌شوند.** در نسخه قدیمی از بخش «پشتیبان کامل شامل پیوست‌ها» خروجی JSON بگیرید و در نسخه نصبی از «بازیابی پشتیبان» وارد کنید.
- قبل از اولین نصب، بازیابی و هر بروزرسانی، پشتیبان بگیرید. نسخه‌های بدون امضای دیجیتال ممکن است اخطار SmartScreen ویندوز نشان دهند.
- حجم پیوست‌ها محدودیت ثابت برنامه ندارد ولی محدود به فضای دیسک/مرورگر داخلی است. ذخیره خودکار در IndexedDB است، نه یک پوشه مستقل از فایل‌های پیوست.
- بروزرسانی فقط کد را تغییر می‌دهد و عمداً پوشه داده را پاک نمی‌کند؛ با این حال حفظ داده بدون پشتیبان تضمین مطلق ندارد.
- این بسته **کد منبع و مسیر ساخت نصب‌کننده** است، نه فایل EXE آماده. برای ساخت، Windows GitHub Actions باید اجرا شود.
